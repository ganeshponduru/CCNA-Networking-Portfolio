# OSPF LSA Types

OSPF routers exchange link-state information using Link-State Advertisements (LSAs). The LSAs are stored in the Link-State Database (LSDB), which is maintained separately for each OSPF area.

This lab focuses on Type 1, Type 2, and Type 3 LSAs.

## Type 1 – Router LSA

- Generated by every OSPF router for each area in which it participates.
- Describes the router's OSPF links and link characteristics within that area.
- Flooded within the originating area; it is not flooded unchanged into other areas.
- Appears under **Router Link States** in the OSPF database output.

## Type 2 – Network LSA

- Generated by the Designated Router (DR) on a broadcast or NBMA multi-access network.
- Describes the shared network and the routers attached to that network.
- Flooded within the originating area.
- Appears under **Net Link States** in the OSPF database output.
- A Type 2 LSA is not generated for every OSPF network type. Point-to-point links do not elect a DR and do not generate Type 2 LSAs.

## Type 3 – Summary LSA

- Generated by an Area Border Router (ABR) to advertise network prefixes from one area into another.
- Allows routers in one area to learn about prefixes located in other areas.
- Flooded within the receiving area.
- Appears under **Summary Net Link States** in the OSPF database output.

An ABR originates Type 3 LSAs for inter-area prefixes. It does not simply convert Type 1 or Type 2 LSAs into Type 3 LSAs.

## Quick comparison

| LSA | Name | Originator | Scope / purpose |
|---|---|---|---|
| Type 1 | Router LSA | Every router, per area | Describes the router's links within an area |
| Type 2 | Network LSA | DR on a multi-access network | Describes the shared network and attached routers |
| Type 3 | Summary LSA | ABR | Advertises inter-area network prefixes |

## How to identify them in the CLI

```text
show ip ospf database
```

The command groups the database entries into Router Link States, Net Link States, and Summary Net Link States. These headings correspond to Type 1, Type 2, and Type 3 LSAs respectively.
