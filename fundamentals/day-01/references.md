# Technical References

These are the technical references I use to check protocol names, port assignments, and networking behaviour while writing my notes.

- IANA, Service Name and Transport Protocol Port Number Registry: https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.xhtml
- RFC 9293, Transmission Control Protocol (TCP): https://www.rfc-editor.org/rfc/rfc9293
- RFC 768, User Datagram Protocol (UDP): https://www.rfc-editor.org/rfc/rfc768
- RFC 791, Internet Protocol: https://www.rfc-editor.org/rfc/rfc791
- RFC 1918, Address Allocation for Private Internets: https://www.rfc-editor.org/rfc/rfc1918
- Wireshark User's Guide: https://www.wireshark.org/docs/wsug_html_chunked/

I write these notes in my own words and use references to check technical details. They are study notes, not a replacement for the official RFCs or product documentation.
